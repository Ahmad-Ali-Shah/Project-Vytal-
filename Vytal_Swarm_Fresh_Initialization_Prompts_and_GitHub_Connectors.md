## 🛠️ Step-by-Step Instructions to Initialize a Fresh Swarm:

1. **Clone Repositories & Install Qoder:**
   Ensure Qoder daemon is running on `http://127.0.0.1:19820`.

2. **Paste Prompts:**
   Copy each agent's initialization prompt into their respective Waker chat window or `MEMORY.md`.

3. **Link GitHub MCP Connectors:**
   Attach the GitHub URIs listed in the table above to each agent under the **Connectors** tab.

4. **Start the Closed-Loop Swarm:**
   Run `npm run swarm:loop` or click **"Trigger Live Swarm Peer Loop"** on the dashboard at `http://127.0.0.1:5173/`.
